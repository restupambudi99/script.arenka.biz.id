## Storyboard Studio (MVP foundation)
- Route: `https://script.arenka.biz.id/studio` (`src/pages/studio.astro`)
- React editor: `src/components/storyboard/StoryboardStudio.tsx` and `storyboard-studio.css`
- Opened from the Content Script sidebar. It supports project brief, paste/import of ChatGPT script, editable scenes, continuity notes, per-scene image reference, Flow prompt assembly, local autosave, JSON export, and prompt text export. A clean browser session loads the most recently edited D1 project for the signed-in editor.
- The studio keeps a localStorage copy for offline fallback; authenticated projects and uploaded images sync to D1/R2 across devices.
- D1/R2 sync is deployed. Production migration `0001_storyboard_studio.sql` was applied to D1 on November 22, 2026. It requires an EmDash editor session and stores projects/assets per owner. `astro.config.mjs` shares the session cookie with `.arenka.biz.id` so the script subdomain can use the apex CMS login.
- The studio keeps local browser storage as an offline fallback; D1 sync requires login and a successful database migration. R2 accepts JPEG/PNG/WebP up to 8 MB, and image reads are private to the owning editor.
- Codex still generation uses the OpenAI-compatible 9Router Images API at `/v1/images/generations` with `cx/gpt-image-2`; server-only `NINEROUTER_API_KEY`, up to two project-owned references, private R2 output, and 10 attempted generations per user per rolling 24 hours. The user reports `https://9routers.vpsarenka.site` now returns the login page with HTTP 200 and valid TLS.
- The default and example `NINEROUTER_BASE_URL` is `https://9routers.vpsarenka.site` (origin only; do not append `/v1`). Local `.env` is ignored by Git. Production Worker secret `NINEROUTER_API_KEY` is configured; Wrangler lists its name and type only. The local `.env` key was streamed as stdin to Wrangler without printing its value. Never read, log, or commit secret values. The account needs entitlement to the selected Codex image model.
- The user-provided Omni Flash 1.2 is still used manually in Flow for video generation.
- The Flow video is still created manually by the user. The studio generates storyboard still images and Flow prompts, not video.
- Preserve Astro + React/EmDash. No Next.js/Tailwind/shadcn migration is required to use this MVP; its current standalone CSS keeps the integration small.

## Before the next deploy
1. Check current branch and worktree.
2. `npm run typecheck`
3. `npm run build`
4. Production deploy and Worker secret are complete on the Arenkabiz account. Wrangler device OAuth credentials are stored outside the repository in the temporary `codex-wrangler-arenkabiz` config directory; set `XDG_CONFIG_HOME` to that path for future CLI operations.
5. Verify the logged-in editor session across the apex and subdomain, project sync, R2 image upload, and generated-image flow. This end-to-end flow still needs an authenticated browser session; no image generation was performed during deployment.
6. Verify `https://script.arenka.biz.id/generator`, `/studio`, the six navigation modules, and the Copywriter GPT handoff.

`worker-configuration.d.ts` is generated by `wrangler types`/Astro's Cloudflare integration and is intentionally excluded from Git. Run `npm run typecheck` to regenerate local binding types.

The generator is prompt-only. “Buka Copywriter GPT” copies the generated prompt and opens `https://chatgpt.com/g/g-Ji2QOyMml-copywriter-gpt-marketing-branding-ads` in a new tab. ChatGPT does not accept the prompt via this link, so the user pastes it into the GPT chat.
