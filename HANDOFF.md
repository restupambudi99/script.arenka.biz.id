## Before next deploy
1. Check current branch and worktree.
2. `npm run typecheck`
3. `npm run build`
4. Deploy with the Arenkabiz Cloudflare identity. Keep Wrangler credentials outside the repo.
5. Verify `https://script.arenka.biz.id/generator`, the six navigation modules, and `/api/script-generate`.

`worker-configuration.d.ts` is generated by `wrangler types`/Astro's Cloudflare integration and is intentionally excluded from Git. Run `npm run typecheck` to regenerate local binding types.

AI requests use the OpenAI-compatible 9Router endpoint in `wrangler.jsonc` (`AI_API_BASE_URL`) and model `kr/claude-sonnet-4.5` (`AI_MODEL`). The secret `AI_API_KEY` is read from the Worker environment. For local development, fill `.env`; for production, run `npm exec -- wrangler deploy --secrets-file .env` from this project directory. `.env` is ignored by Git. The configured endpoint uses plain HTTP, so the API key and prompts are not encrypted in transit; switch the base URL to an HTTPS endpoint before using sensitive prompts.

The endpoint caps input at 12,000 characters and allows up to five generations per IP per UTC day via KV. Treat this as an initial abuse guard; if the app sees significant public usage, review rate limiting and authentication.
